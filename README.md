# Ticketmaster Automation App

An Electron application with Selenium WebDriver integration for automating Ticketmaster interactions.

## Prerequisites

- Node.js (v14 or higher)
- Chrome browser installed
- ChromeDriver (matching your Chrome version)

## Setup

1. Install dependencies:
```bash
npm install
```

2. Build the TypeScript files:
```bash
npm run build
```

3. Start the application:
```bash
npm start
```

## Features

- One-click navigation to Ticketmaster website
- Automatic form filling in iframes
- Selenium WebDriver integration for automation

## Important Notes

- Make sure ChromeDriver is installed and matches your Chrome browser version
- The application needs appropriate permissions to control the Chrome browser
- Some websites may have anti-automation measures in place

## Development

- Source files are in the `src` directory
- TypeScript compilation outputs to `dist` directory
- Use `npm run watch` for development with auto-compilation # test-electron
